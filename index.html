What we built

One portable core powers Cara’s standalone apps. We work on rendering accuracy, shader reuse, and CPU efficiency together, then test changes on real phones, handhelds, and computers.

Rendering accuracy

Lighting, fog, transparency, and both screens matter. We compare rendered output and game behavior while improving the graphics pipeline.

Rendering tuned for real hardware

OpenGL and OpenGL ES reuse textures, shaders, and graphics state to reduce repeated work. Adreno, Mali, and Apple GPU tuning is tested separately.

FastInterp and optional JIT

FastInterp runs games without JIT. Optional JIT is available on Mac and supported Android builds. Both use the same graphics core.

Cara builds on Citra and Citra MMJ and adapts Azahar’s FastInterp. The core and app are open source under GPL-2.0-or-later.

Software preservation

Cara exists to preserve the legacy of Nintendo games and help players revisit the experience as faithfully as possible. Cara includes no Nintendo code or game assets. We do not support piracy.

Cara is an independent project with no affiliation to Nintendo.
