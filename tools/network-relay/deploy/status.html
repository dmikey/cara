Connect two players

  1. Use two separate Cara installations with the relay feature and separate game saves. Each player needs a compatible game and local multiplayer unlocked.
  2. Open Settings → Local multiplayer → Private room from the library, or Local multiplayer from the running game’s menu. If this option is missing, that installation needs an updated Cara build.
  3. Keep the server address wss://carap2p.therad.ninja/relay. Both players enter the same existing room name and password, then tap Join room. Get these privately from the relay administrator. This page does not create rooms.
  4. Wait until both players show Connected, return to the game, then select its local wireless mode. Keep Cara in the foreground.

Testing Pokémon

Pokémon trading and battles have not yet been verified in Cara. The relay, native transport and emulator wireless-service tests have passed separately. A connected room is the starting point for a game test.

Start with matching game versions and updates, separate trainer saves and a small local action: discover the other player, request a local battle or trade, and accept on the other device. Record the exact game, versions and the first step that fails. Back up both in-game saves before attempting a trade.

Use the game’s local wireless option. This relay does not restore Nintendo Internet services or StreetPass. Leaving Cara or loading a save state disconnects the room; reconnect both players before trying again.

No credentials are collected on this page. Room passwords belong only in Cara.
